# Build a Little Pause Android APK (Windows)

This folder contains a Capacitor Android wrapper. It loads the deployed Little Pause app inside an Android app shell. The FastAPI server must be deployed and reachable over HTTPS first; the journal database remains on the server.

## Before you begin
- Deploy the FastAPI project to Railway and set up a persistent volume at `/data` with `DATABASE_PATH=/data/journal.db`.
- Install Node.js LTS and Android Studio on Windows.
- In Android Studio, install the Android SDK and a compatible JDK/SDK platform when prompted.

## Build the Android project
1. Edit `capacitor.config.ts` and replace `https://REPLACE-WITH-YOUR-RAILWAY-DOMAIN` with your real Railway HTTPS domain (no trailing slash).
2. Open PowerShell in this `android-wrapper` folder.
3. Run:
   ```powershell
   npm install
   New-Item -ItemType Directory -Force www | Out-Null
   Set-Content -Path www/index.html -Value '<!doctype html><html><head><meta charset="utf-8"><meta name="viewport" content="width=device-width, initial-scale=1"></head><body>Opening Little Pause…</body></html>'
   npx cap add android
   npx cap sync android
   npx cap open android
   ```
4. Android Studio opens. Wait for Gradle sync to finish.
5. To build a test APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Find the generated APK under `android/app/build/outputs/apk/debug/` and transfer it to your Android phone.
7. On the phone, allow installing apps from that source if Android asks, then tap the APK to install.

## For Play Store
Use **Build → Generate Signed Bundle / APK** and choose **Android App Bundle** for Google Play (or APK for direct distribution). Create and securely back up a signing key. Keep passwords and keystore out of GitHub. Complete Play Console's current policy, testing, privacy, and store-listing requirements.

## Important
- This wrapper is not a compiled APK. The APK is generated by Android Studio on your computer.
- It needs an internet connection to load the deployed server. It is not an offline-first native application.
- Do not connect this to real private journaling until login, per-user authorization/data separation, HTTPS, and a privacy policy are implemented and tested.
